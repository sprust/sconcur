# Контекст корутины

`SConcur\Context\Context` — key-value хранилище, привязанное к текущей корутине
(её файберу), изолированное между конкурентными корутинами и наследуемое
потомками. Оно переносит состояние запроса (сам запрос, пользователь, локаль)
через `suspend`/`resume` без общих синглтонов, которые соседняя корутина
перезатёрла бы. Хранилище держит произвольные `mixed` значения по строковым ключам
и ничего о них не знает, поэтому не зависит от фреймворка.

## API

```php
use SConcur\Context\Context;

$context = Context::current();      // контекст текущей корутины (вне файбера — корневой)

$context->set('user', $user);       // локальная запись в текущую корутину
$context->find('user');             // значение или null (с учётом наследования)
$context->has('user');              // виден ли ключ (свой или унаследованный)
$context->forget('user');           // удалить только локальный ключ
```

`Context::current()` возвращает `CoroutineContext`, закреплённый за id текущего
файбера на момент вызова, поэтому ссылка переживает `suspend`/`resume` этой же
корутины. В `set(string $key, mixed $value, bool $replace = false)` значение по умолчанию
`replace: false` не перезаписывает существующий локальный ключ.

## Семантика

Привязка идёт по `Fiber::getCurrent()` — тому же маркеру, по которому
`State::getCurrentFlow()` определяет флоу, — поэтому у каждой корутины
(порождённого через `spawn` обработчика запроса, каждой корутины `WaitGroup`)
своя локальная карта. Чтение идёт сквозным подъёмом по цепочке родителей:
сначала своя карта, потом родительская, до корня процесса. Запись всегда
локальна, поэтому потомок может затенить родительский ключ, не трогая ни
родителя, ни соседей.

Родитель фиксируется при создании корутины — им становится тот, кто вызвал
`Scheduler::spawn` или `WaitGroup::add`. Корутина, созданная вне файбера, наследует
от корневого контекста, общего на процесс; вне файбера `Context::current()`
возвращает этот корень, а не бросает исключение, поэтому код начальной загрузки
работает как обычно.

```php
Context::current()->set('request', $request);

$group = WaitGroup::create();

$group->add(static function () {
    // наследует 'request' от породившей корутины
    $request = Context::current()->find('request');
});

$group->waitAll();
```

## Жизненный цикл и ограничения

Локальная карта создаётся лениво (на первом `set`) и освобождается вместе с
корутиной — там, где библиотека сбрасывает учёт по файберам
(`State::unRegisterFiber`), поэтому N завершившихся корутин не оставляют после себя
N контекстов; корневой контекст не удаляется.

Среда кооперативная и однопоточная, блокировок нет. `find`/`has`/`set` — это O(1) по
своей карте плюс подъём по цепочке родителей, глубина которой обычно 1–2. Размер
значений — дело вызывающего: библиотека их не интерпретирует, но гарантирует
освобождение вместе с корутиной.
